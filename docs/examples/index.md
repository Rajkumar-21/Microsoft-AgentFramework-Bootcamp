    All examples are in the [`examples/`](https://github.com/Rajkumar-21/Microsoft-AgentFramework-Bootcamp/tree/main/examples) folder on GitHub. Clone the repo and run them locally:

    ```bash
    git clone https://github.com/Rajkumar-21/Microsoft-AgentFramework-Bootcamp.git
    cd Microsoft-AgentFramework-Bootcamp
    uv sync
    uv run python examples/mcp-clients/mcp-client-stdio-package.py
    ```
