# Module 14: Agent-as-Tool

## Learning Objectives
- Use one agent as a tool for another agent (hierarchical agents)
- Understand `agent.as_tool()` method
- Build parent-child agent hierarchies
- Create specialization patterns

## Key Concepts
- **`agent.as_tool()`** - Expose an agent as a callable tool
- **Hierarchical agents** - Main agent delegates to specialist agents
- **Composition** - Combine multiple agent-tools for complex tasks

## Exercises
1. Create a main agent that delegates to specialist agent-tools
2. Build a research assistant with sub-agents for different domains
3. Compare agent-as-tool vs workflow patterns
