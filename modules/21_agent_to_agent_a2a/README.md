# Module 21: Agent-to-Agent Communication (A2A)

## Learning Objectives
- Understand the A2A (Agent-to-Agent) protocol
- Build agents that communicate via standardized protocols
- Implement inter-agent messaging patterns
- Design loosely-coupled multi-agent systems

## Key Concepts
- **A2A Protocol** - Standardized agent communication protocol
- **Agent Cards** - Agent capability descriptions
- **Task delegation** - Structured task exchange between agents
- **Protocol interoperability** - Agents from different systems communicating

## Exercises
1. Create agents that exchange structured messages
2. Implement agent discovery via agent cards
3. Build a multi-agent system with A2A communication
