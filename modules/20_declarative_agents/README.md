# Module 20: Declarative Agents

## Learning Objectives
- Define agents using YAML/configuration files
- Understand the declarative agent pattern in Python
- Load agent definitions from config without code changes
- Compare declarative vs imperative agent creation

## Key Concepts
- **Declarative agents** - Define agents via YAML/config instead of code
- **Agent definitions** - Name, instructions, tools, model in config
- **Configuration-driven** - Change behavior without code changes
- **Dynamic loading** - Load multiple agents from a config file

## Exercises
1. Define agents in a YAML config file
2. Load and instantiate agents from config
3. Modify agent behavior by changing only the config
4. Build a config-driven multi-agent system

## Files
- `agents.yaml` - Agent definitions in YAML
- `main.py` - Load and run agents from config
