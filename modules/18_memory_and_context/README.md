# Module 18: Memory & Context Management

## Learning Objectives
- Understand agent memory and context systems
- Use ChatHistoryProviders for conversation persistence
- Use ContextProviders for injecting dynamic context
- Manage sessions and state across agent interactions

## Key Concepts
- **Sessions** - Isolated state per conversation
- **ChatHistoryProviders** - Store/retrieve conversation history
- **ContextProviders** - Inject dynamic context into agent prompts
- **Memory services** - External memory stores (Cosmos DB, etc.)

## Exercises
1. Implement a simple in-memory chat history provider
2. Create a context provider that injects user profile data
3. Build a session-aware agent that remembers across restarts
