Handoff Workflows

Some problems don't flow in a straight line — they need routing. A handoff workflow lets a triage agent pass the conversation to the right specialist, who can hand it back or onward. You'll build the Harbor support desk: triage reads the ticket and delegates to Billing, Technical, or Refunds.

The routing mesh

Harbor: triage delegates to specialists

    T -->|wants money back| R["💸 Refunds"]

Triage decides; specialists own their domain and can return control when the issue falls outside it.

1 · Build triage and specialists

main.py
import asyncio
from agent_framework import HandoffBuilder
from agent_framework.azure import AzureOpenAIChatClient


async def main() -> None:
    client = AzureOpenAIChatClient()

    triage = client.create_agent(
        name="Triage",
        instructions=(
            "You are the front desk for Harbor support. Read the customer's "
            "message and hand off to the right specialist. Don't try to solve "
            "it yourself."
        ),
    )
    billing = client.create_agent(
        name="Billing",
        instructions="You resolve invoice, subscription, and payment questions.",
    )
    technical = client.create_agent(
        name="Technical",
        instructions="You debug product errors and outages. Be precise.",
    )
    refunds = client.create_agent(
        name="Refunds",
        instructions="You process refund requests and explain the policy.",
    )

2 · Define the handoffs

Set the start agent, then declare who can hand off to whom. The builder injects handoff tools so each agent can transfer control by name.

main.py (cont.)
    workflow = (
        HandoffBuilder(
            name="harbor-support",
            participants=[triage, billing, technical, refunds],
        )
        .with_start_agent(triage)
        .add_handoff(triage, [billing, technical, refunds])
        .add_handoff(billing, triage)
        .add_handoff(technical, triage)
        .add_handoff(refunds, triage)
        .build()
    )

    result = await workflow.run(
        "I was charged twice for my October invoice — I want one charge refunded."
    )
    for output in result.get_outputs():
        print(output)


if __name__ == "__main__":
    asyncio.run(main())

Interactive vs. autonomous

  1. Interactive — by default the workflow can pause and emit a request_info event to collect the user's next message, enabling true multi-turn support chats.
  2. Autonomous — provide the full context up front and let triage route once to a specialist that resolves it end-to-end, as above.
💡
Handoff vs. sequential
Use sequential when every item goes through the same steps. Use handoff when the path depends on the content — a billing ticket and a bug report shouldn't take the same route.
🏢
This is how support orgs actually work
Tier-1 triage routing to specialized queues is the dominant model in customer operations. Handoff workflows encode that org chart in code — and because each specialist is its own agent, you can give Billing the payments tools and Technical the diagnostics tools without cross-contaminating their capabilities.
