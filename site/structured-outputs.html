Structured Outputs

A paragraph of prose is fine for a human, but downstream systems need fields. With structured outputs you hand the agent a Pydantic model and get back a validated object — not a string you have to parse with regex. You'll build the Meridian Mutual First Notice of Loss (FNOL) agent: it reads a messy claim description and emits a schema-perfect record ready to drop into a claims system.

Why structured outputs

Free-text answers are unpredictable: today the model writes "policy #A-7781", tomorrow "Policy number A7781". A schema removes the guesswork — the model is constrained to your shape, types are coerced, and missing required fields raise a validation error instead of silently corrupting your pipeline.

The model is constrained to your schema; resp.value is a validated instance you can persist directly.

1 · Define the schema

Model the claim with BaseModel. Use Field(description=...) to guide the model on each attribute, and Enum/typed fields to lock down categorical values. The descriptions become part of the schema the model sees.

schema.py
from enum import Enum
from pydantic import BaseModel, Field


class ClaimType(str, Enum):
    auto = "auto"
    property = "property"
    liability = "liability"
    other = "other"


class Severity(str, Enum):
    low = "low"
    medium = "medium"
    high = "high"


class ClaimIntake(BaseModel):
    """A structured First Notice of Loss record."""

    policy_number: str = Field(description="Policy identifier, normalized to A-NNNN form")
    claimant_name: str = Field(description="Full name of the person reporting the loss")
    claim_type: ClaimType = Field(description="Category of the claim")
    incident_date: str = Field(description="Date of the incident in YYYY-MM-DD format")
    location: str = Field(description="Where the incident occurred")
    severity: Severity = Field(description="Triage severity based on described damage/injury")
    summary: str = Field(description="One-sentence neutral summary of what happened")
    injuries_reported: bool = Field(description="True if any injury was mentioned")
    estimated_amount_usd: float | None = Field(
        default=None, description="Rough loss estimate in USD if stated, else null"
    )

2 · Ask for the schema with response_format

Pass the model through the options dict on run(). The parsed instance is on resp.value; the raw JSON is still on resp.text if you need it.

main.py
import asyncio
from agent_framework.azure import AzureOpenAIChatClient


async def main() -> None:
    agent = AzureOpenAIChatClient().create_agent(
        name="FNOL-Intake",
        instructions=(
            "You are a claims intake specialist for Meridian Mutual. "
            "Extract a clean First Notice of Loss record from the caller's description. "
            "Normalize the policy number to A-NNNN. If a value is not stated, infer "
            "conservatively and never fabricate amounts."
        ),
    )

    call = (
        "Hi, this is Dana Whitfield, policy A 7781. Yesterday, May 3rd, someone "
        "backed into my parked Civic outside the Glenwood Mall in Asheville. "
        "Bumper's cracked, no one was hurt. Probably about twelve hundred bucks."
    )

    resp = await agent.run(call, options={"response_format": ClaimIntake})
    claim: ClaimIntake = resp.value

    print(f"Policy:    {claim.policy_number}")
    print(f"Claimant:  {claim.claimant_name}")
    print(f"Type:      {claim.claim_type.value} · severity {claim.severity.value}")
    print(f"Incident:  {claim.incident_date} @ {claim.location}")
    print(f"Injuries:  {claim.injuries_reported}")
    print(f"Estimate:  ${claim.estimated_amount_usd:,.2f}")
    print(f"Summary:   {claim.summary}")


if __name__ == "__main__":
    asyncio.run(main())
💡
value vs. text
resp.value is your typed model instance. resp.text is the raw JSON string. If parsing fails, value is None — check for it before using.

Streaming + structured output

You can stream and get a parsed result. Iterate for live updates, then call get_final_response() — the stream's finalizer parses the schema for you.

streamed parse
stream = agent.run(call, stream=True, options={"response_format": ClaimIntake})
async for update in stream:
    if update.text:
        print(update.text, end="", flush=True)

final = await stream.get_final_response()
claim = final.value  # fully parsed ClaimIntake
🏢
Schemas are your API contract
When an agent feeds a database, a queue, or another service, the Pydantic model is the interface. Version it like any contract, keep required fields minimal, and let optional fields default to None so the model never has to invent data. This is the bridge from "chatbot" to "system component".
