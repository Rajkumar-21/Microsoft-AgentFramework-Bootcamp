Commerce Concierge

Commerce Concierge is a customer-facing retail agent. It finds products, checks availability, prepares an order, and escalates to a human when unsure. It shows a different slice of the framework from Ops Copilot: structured outputs, sequential / concurrent / handoff workflows, streaming, and agent-to-agent (A2A) calls.

📁
Where it lives
Source: projects/commerce-concierge/. It discovers a published warehouse agent from the Agent Registry and calls it over A2A, and self-registers so storefronts can embed it.

Intent is parsed into typed data, research runs in parallel, a single product is chosen, an order is drafted, and anything uncertain is handed to a human or reserved with the warehouse over A2A.

1 · Typed outputs at every stage

Pydantic models make the pipeline's hand-offs predictable — each stage returns structured data, not free text.

app/schemas.py
from pydantic import BaseModel, Field

class ProductPick(BaseModel):
    sku: str
    name: str
    price: float
    why: str = Field(description="One-sentence reason this fits the shopper.")

class OrderDraft(BaseModel):
    sku: str
    quantity: int = 1
    unit_price: float
    shipping_estimate: float
    total: float
    needs_human: bool = Field(default=False, description="Human must confirm before placing.")

2 · Agents bound to their output schema

app/agents.py
recommend = client.create_agent(
    name="Recommend",
    instructions="Pick the single best product for the shopper given the research.",
    response_format=ProductPick,
)
quote = client.create_agent(
    name="Quote",
    instructions="Prepare an OrderDraft incl. shipping; set needs_human if price > $150.",
    tools=[estimate_shipping],
    response_format=OrderDraft,
)

3 · Compose sub-workflows: concurrent inside sequential, wrapped in handoff

app/workflow.py
from agent_framework import ConcurrentBuilder, HandoffBuilder, SequentialBuilder

research = ConcurrentBuilder(participants=[catalog, reviews, inventory]).build()

pipeline = SequentialBuilder(participants=[
    understand,
    research.as_agent(name="Research"),     # a sub-workflow as one step
    recommend,
    quote,
]).build()

concierge = HandoffBuilder(
    participants=[pipeline.as_agent(name="Pipeline"), support]
).build()

4 · Reach the warehouse over A2A (discovered from the registry)

app/agents.py
from agent_framework.a2a import A2AAgent
from .registry import discover_warehouse_url

url = await discover_warehouse_url()            # find a published 'warehouse' agent
warehouse = A2AAgent(name="Warehouse", url=url) if url else None
