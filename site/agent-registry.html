Agent Registry & Marketplace

Once you have many agents, MCP servers, and skills, teams need a place to publish, discover, and govern them. The Agent Registry is a runnable marketplace: a FastAPI service secured by Microsoft Entra ID OAuth2, backed by Cosmos DB, with a React UI and a client SDK so any Agent Framework agent can self-register and pull approved capabilities at runtime.

📁
Where it lives
All source is in agent-registry/ in the repo. The two reference apps in projects/ — Ops Copilot and Commerce Concierge — both use this registry.

Agents and the UI authenticate with Entra ID; the API validates the token and reads/writes a store that is in-memory for dev and Cosmos DB (keyless, RBAC) in production.

Three resource types

KindRepresentsKey fields
AgentA deployed agent endpointendpoint, protocol (a2a / openai / azure_functions), auth, scopes
MCP ServerA tool serverurl, transport (streamable_http / stdio / websocket), tools
SkillA reusable prompt / tool / workflowskill_kind, spec (YAML), inputs, outputs

The permission model

Authorization uses three layered scopes. Delegated (user) tokens carry them in the scp claim; app (client-credentials) tokens carry them in roles.

ScopeGrants
Registry.ReadList and read catalog entries
Registry.PublishRead + publish/update your own entries
Registry.ManageFull control, including deleting others' entries

1 · A token-validated, scoped API

Every request is authenticated. In production the API verifies the JWT signature against the tenant JWKS and checks the audience, issuer, and expiry; locally you can pass a dev token.

app/routers/agents.py
from fastapi import APIRouter, Depends
from ..security import require_read, require_publish, require_manage

router = APIRouter(prefix="/agents", tags=["agents"])

@router.get("")                       # needs Registry.Read
async def list_agents(principal=Depends(require_read), store=Depends(get_store)):
    items, total = await store.list("agent", visible_to_org=principal.tenant_id)
    return Page(items=items, count=len(items), total=total)

2 · Keyless Cosmos DB storage

Production uses one container per kind with a high-cardinality partition key (/partition_key = publisher id), a singleton client, and keyless DefaultAzureCredential auth — exactly the practices the bootcamp's Cosmos guidance recommends.

app/storage/cosmos.py
from azure.cosmos.aio import CosmosClient
from azure.identity.aio import DefaultAzureCredential

class CosmosStore:
    def __init__(self, settings):
        # keyless: managed identity / az login — no secrets in code
        self._client = CosmosClient(settings.cosmos_endpoint, DefaultAzureCredential())

    async def list(self, kind, *, visible_to_org=None, query=None, tags=None, ...):
        sql = "SELECT * FROM c WHERE 1=1"
        params = []
        if query:                       # targeted, parameterized search
            sql += " AND CONTAINS(LOWER(c.name), @q)"; params.append({"name": "@q", "value": query.lower()})
        # ... ARRAY_CONTAINS for tags, COUNT for total, OFFSET/LIMIT for paging

3 · Agents self-register with the SDK

The client SDK lets any Agent Framework agent advertise itself and turn registered MCP servers into live tools — discovery becomes one call.

using the registry SDK
from registry_client import RegistryClient

async with RegistryClient(base_url="https://registry.internal", credential=cred,
                          api_audience="api://registry") as reg:
    # advertise this agent so other teams can find it
    await reg.register_agent(name="Ops Copilot", endpoint=my_url, protocol="azure_functions")

    # discover approved MCP servers and get ready-to-use tools
    tools = await reg.build_mcp_tools(tag="operations")

agent = AzureOpenAIChatClient().create_agent(name="Ops", instructions="...", tools=tools)

# UI
cd ui && npm install && npm run dev # http://localhost:5173

Dev auth: send  Authorization: Bearer dev  (admin) or  Bearer dev Registry.Read

Deploy to Azure

The registry ships with Bicep + azd: one command provisions Azure Container Apps, a serverless Cosmos DB account (disableLocalAuth=true), a user-assigned managed identity with Cosmos data-plane RBAC, ACR, and Log Analytics.

deploy
cd agent-registry
azd up    # provisions Container Apps + Cosmos + managed identity + ACR + Log Analytics

Why this matters
A registry turns scattered agents into a governed platform: capabilities are authenticated, authorized by scope, scoped per tenant, and discoverable. It is the connective tissue between the apps you build in Ops Copilot and Commerce Concierge.
