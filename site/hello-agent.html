Hello Agent

Build the Contoso Financial Expense Policy Assistant — your first real agent. It answers employee expense questions from a system prompt that encodes actual policy, using one chat client and a single run() call.

One agent, one client, one model call — grounded by instructions.

Step 1 — Build the chat client

build the client
import os
from agent_framework.azure import AzureOpenAIChatClient

client = AzureOpenAIChatClient(
    endpoint=os.environ["AZURE_OPENAI_ENDPOINT"],
    api_key=os.environ["AZURE_OPENAI_API_KEY"],
    deployment_name=os.environ["AZURE_OPENAI_CHAT_DEPLOYMENT_NAME"],
)

Step 2 — Encode the policy as instructions

The system prompt is the agent's contract. Contoso's expense rules go here, in plain language.

system prompt
SYSTEM_PROMPT = """
You are Contoso Financial's Expense Policy Assistant. Answer employee questions
using these rules:

- Meals: up to $75/person domestic, $120/person international.
- Entertainment: requires pre-approval; cap $200/person.
- Airfare: economy only for flights under 6 hours.
- All claims must be submitted within 30 days of the expense.

Be concise. State whether a claim is reimbursable, the relevant limit, and any
condition (e.g. pre-approval). If a request exceeds policy, say so plainly.
"""

Step 3 — Create the agent and run it

modules/02_hello_agent/main.py
import asyncio


async def main() -> None:
    agent = client.create_agent(name="ExpenseAssistant", instructions=SYSTEM_PROMPT)

    question = (
        "I took a client to dinner in Seattle. The bill was $90 per person for "
        "two people. Is that reimbursable?"
    )
    response = await agent.run(question)
    print("Agent:", response.text)


if __name__ == "__main__":
    asyncio.run(main())

Run it

🏢
Instructions are a contract
The system prompt is where your policy lives. Treat it like code: version it, review it, and test edge cases. A vague prompt produces vague — and non-compliant — answers.
💡
Reuse the client
Create the AzureOpenAIChatClient once and reuse it across agents and requests. Don't construct a new client per call.
